# Type outlines

- Body: [LXGW WenKai](https://github.com/lxgw/LxgwWenKai), Regular. SIL Open Font License 1.1, included in `LICENSE.LXGWWenKai`.
- Headings: [Caveat](https://github.com/google/fonts/tree/main/ofl/caveat), default regular instance. SIL Open Font License 1.1, included in `LICENSE.Caveat`.

`glyphs.json` is a set of character outlines and advances compiled with FontTools. The SVGs include only the outlines they actually use, with no font installation or external resource required by readers. Printable ASCII is retained for dates, contribution counts and English repository names. Font sources are authoring inputs, not runtime dependencies.
